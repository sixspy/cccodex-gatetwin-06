# 闸对

中文名：**闸对** · 前缀 `gatetwin` · 端口 **6500 / 11500**

## 孤儿出站口径（全局唯一）

**当场旁路终态**：装载路径遇到无在途开腿的出站，当场进旁路匣（原因=出站孤儿），
刷卡点命运同成败置「已旁路」；不写行程、不造虚进、不入待配缓冲（无缓冲表，
只读接口 `缓冲键` 恒为 null）。旁路为终态，后续同卡进站只开新腿，不回放配对。

- 只读接口：`GET /api/孤儿出站`（可选 `卡号` / `事件编号` 过滤），每行含
  卡号、出站事件、处置、旁路键、缓冲键(恒 null)、valid 裁决。
- 双落硬闸：旁路匣对事件编号部分唯一索引；并发裁决下同一出站至多一行，
  绝不旁路与行程双落；半截失败随整批事务回滚。
- 贯验协同：孤儿刷卡命运必须为已旁路终态、行程账无双落、已旁路出站必有匣行。
- 夹具：`孤儿单独出站样例`（旁路无缓冲）、`孤儿后补进站样例`（后补进站仍旁路）。

## 骨架

**刷卡点装载 → 同卡进站出站成对物化 → 缺腿/异向/超时旁路 → 行程账与刷卡点互证**

皮：地铁/公交闸机刷卡。去皮是 **OD 成对管道 + 开腿态 + 旁路 + 行程贯验**，不是票务售票 CRUD、不是乘车码业务页、不是日结封账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6500
# 刷卡流 → 灌「成对样例」→ 看开腿账/行程账 → 再灌「缺腿超时样例」「出站孤儿样例」→ 行程贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 刷卡点 | 带卡号/站点/方向/事件时的进出闸事件 |
| 开腿账 | 已进站尚未出站的在途开腿 |
| 行程账 | 进站+出站成对后的正式行程 |
| 旁路匣 | 缺腿超时 / 出站孤儿 / 重复进站等 |
| 行程贯验 | 成对刷卡 ↔ 行程笔数 ↔ 旁路命运互证 |
